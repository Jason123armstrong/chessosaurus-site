# chessosaurus.com

The Chessosaurus website: plain HTML and CSS, no build step, hosted free on GitHub Pages.

- No cookies, analytics or outside requests (no web fonts, no scripts from other sites).
- Pages: `index.html` (home), `grown-ups.html`, `privacy.html` (the Google Play privacy policy link), `help.html`, `404.html`.
- Screenshots in `img/` are from the app on the emulator (11 Nov 2026), resized to 540 px wide.
- `CNAME` points GitHub Pages at www.chessosaurus.com.

Keep the privacy policy in step with the app (error reports, permissions, two-device play).
